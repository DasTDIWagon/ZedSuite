CHANGES
1. GN4308 SOI limiter: retain known 12x5 F9/C5 tables at 0x5AFFC and
   0x7AFFC when a modified monotonic temperature axis exceeds stock ranges.
   Preserve Kelvin*10 decoding; add a warning to suspicious calibration.
   Do not relabel the values using a guessed alternate temperature encoding.
2. IQ by MAP: recognize extended DA pressure axes through 4000 raw/mbar
   for the scoped structure, using monotonicity/start/range checks to avoid
   misclassifying N75 maps with a different axis range.
3. MAP linearization: admit DC9C upper-pressure endpoints 3501..5000 with
   existing ADC/low-pressure checks. Preserve factor 1.0. This does not
   validate any installed sensor's electrical or ECU operating range.
4. Three adjacent 64 KiB calibration banks: for the exact 512 KiB signature
   layout 0x50000/0x60000/0x70000, shift grouping boundaries by -0x4000.
   CB1 [4C000,5C000), CB2 [5C000,6C000), CB3 [6C000,7C000).
   This restores per-bank MAF-temperature detection and driver-wish grouping.
   Existing separated two-bank grouping is preserved.
5. Inverse driver wish: preserve EDC15VM results through app finalization;
   retain the prior filtering for other ECU families and MAF linearization.
6. Start IQ: recognize both 9x9 and GQ 9x8 structures with scoped axis families.
   A stock 9x8 table is displayed as 9x8; detection does not resize ECU data.
7. Tools -> Multi-Map Beta: three selector choices, mandatory acknowledgement,
   exact program fingerprints and layout checks, editable-version requirement,
   current unsaved calibration edits included, checksum correction and recheck.
8. Vehicle configuration and source bank are independent required choices.
   Copy the chosen current/saved CB1, CB2 or CB3 source, never a guessed stock
   calibration. Empty/unsupported sources are refused. FD CB2 is AG, not 4x4.
   All-bank mode clones to CB1/CB2/CB3; first/final IDs retained, middle ID 3.
   Only manual CB1 permits partial CB2 copying while retaining CB3.
   Source table sizes are kept: SG Start IQ 9x9, AG 9x8 in inspected files.
9. Separate GK KD34 profile: own fingerprint/identities/IDs/checksum words;
   clone GK's own calibration, not GN tables. Shared selector is experimental.
10. This refresh updates the operating text: press AND release the second
    control while holding the first. Explicitly disclose missing engine-off
    guard and unverified tach-to-editor bank-number association.

11. Tools > ECU Compatibility: eleven exact main-program groups, inspected
    ECU/software identities and 48/64 KiB bank spacing; informational only.
12. Include unsaved edits checkbox: checked uses the working snapshot;
    unchecked reconstructs the selected saved version (not stock/Ori).
    Saved-data read errors are fatal, not a fallback to original bytes.
    Full generated byte delta is staged against the raw version base; stale
    cell/axis overlays cleared so old target edits cannot undo cloning.
    Excluded unsaved edits are discarded on apply; UI discloses this.
    Neither vehicle choice converts gearbox settings nor SG/AG proves tuning.
    4x4 has no verified source/profile and is unavailable. Automatic requires
    the experimental brake + SET selector. No runtime claim is added.
